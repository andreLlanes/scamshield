title: Tech Support and Remote Access Scams
category: tech_support
authority: industry-standard

# Software vendors do not make unsolicited support calls

Microsoft, Apple, Google, and antivirus vendors do not phone users about
infections, error reports, or expired licences. They have no ability to detect a
virus on a specific consumer machine and no mechanism that maps such a detection
to a phone number. An unsolicited call claiming otherwise is an impersonation.

# Internet providers do not need remote control of your phone

A genuine ISP diagnoses line and equipment faults from its own network side or
by dispatching a technician. It does not need to install a screen-sharing app on
a customer's phone, and it never needs the customer's banking credentials or an
SMS verification code to fix a connection.

# Remote access apps hand over the account, not just the screen

AnyDesk, TeamViewer, QuickSupport, and similar tools give the caller live view
and control of the device. Once installed, the caller can watch credentials
being typed, open the banking app, initiate transfers, and read the OTP that
arrives — all from the victim's own trusted device, which defeats device-based
fraud checks.

# Subscription refund calls are a pretext to open banking

The "your antivirus auto-renewed for a large amount, let me refund it" script
exists to get the victim into their online banking with the scammer watching.
Real refunds are issued back to the original payment method automatically and
require no live session, no screen sharing, and no logging in during a call.

# Warning pop-ups with phone numbers are fake

Browser pop-ups that lock the screen and display a support number are not
generated by the operating system or the browser vendor. Legitimate security
warnings never instruct a user to call a phone number.

# Never share a code that arrives while a stranger is on the line

Any code delivered by SMS or authenticator during a support call authorises
something. If the caller needs it, the caller is the one performing the action
being authorised.
